# Artificial Intelligence

Jupyter notebook solutions for the **Artificial Intelligence** course at **ECE NTUA**, academic year **2024–2025**.

## Contents

- `Solution_AI_25_LabEx1.ipynb` — maze search algorithms, A* heuristics, algorithm comparison, visualization, and adversarial ghost avoidance.

- `Solution_AI_25_LabEx2.ipynb` — movie recommendation system using metadata, Prolog rules, user ratings, and precision/recall/F1 evaluation.

## Requirements

The notebooks are intended for Jupyter Notebook or Google Colab.

Main tools used:

- Python

- pandas, numpy, matplotlib, scikit-learn

- SWI-Prolog

- pyswip

Lab 2 may require external dataset files such as `movies_metadata.csv` and `ratings.csv`.
